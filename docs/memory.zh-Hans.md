# 记忆

[English](memory.md)

预设跨会话保存持久的项目记忆，默认开启。本页介绍记忆的存储、加载和持久化方式、默认值以及限制。

## 存储

记忆位于工作区相对根目录下，默认为 `.zcode/memory`，可通过 `workspaceMemoryRoot` 配置。两个文件很重要：

- `MEMORY.md` 是索引，是被注入上下文的内容。
- `FACTS.md` 保存提取写入的持久事实，每条事实一个 Markdown 列表项。索引携带指向它的链接。

提取和读取都以会话沙箱策略指定的工作区根目录为基准，使用同一个记忆目录。该根必须是非空的工作区相对路径，解析器强制记忆文件留在工作区根之内，包括处理符号链接逃逸。改变工作目录的会话保持一个记忆根。

## 加载

每次请求时，预设读取 `MEMORY.md` 并把它作为系统提醒注入上下文，供模型回忆已记录的事实。注入的文本受 `memoryMaxBytes` 约束，默认为 32768 个 UTF-8 字节。索引超过预算时，超出部分被截断并附加截断说明。索引文件不存在时，不注入任何内容。

## 持久化

提取在符合条件的交互轮次结束后运行。它读取最近的对话，向模型请求持久事实，把它们合并进 `FACTS.md` 而不重复已有条目，并确保 `MEMORY.md` 指向事实文件。写入经由会话的沙箱策略。

三种情况会跳过提取：`headless` 开启时、该轮已直接写入记忆时，以及该轮失败时。提取并非每轮都运行。

## 默认值

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| `memoryEnabled` | 开 | 启用记忆上下文。 |
| `memoryExtractionEnabled` | 开 | 从交互会话中提取持久记忆。 |
| `memoryMaxBytes` | 32768 | 注入索引的最大 UTF-8 字节预算。 |
| `workspaceMemoryRoot` | `.zcode/memory` | 记忆文件的工作区相对根目录。 |

`memoryExtractionEnabled` 与 `memoryEnabled` 分别控制提取和读取。关闭提取后仍可读取已有记忆。

## 限制

上游 ZCode 将 `MEMORY.md` 限制在 200 行、25000 个字符以内。负责提取记忆的子 agent 要求用户文本至少有三个符合条件的词，当前轮次已直接写入记忆时会跳过提取。写入工具只能修改记忆目录。本预设采用上文列出的字节上限和提取条件。[上游索引限制](https://github.com/zai-org/ZCode/blob/fec975905a2abd4c07e35c40d51fa097a2258ec9/apps/zcode-cli/packages/core/src/memory/index-content.ts) · [提取规则](https://github.com/zai-org/ZCode/blob/fec975905a2abd4c07e35c40d51fa097a2258ec9/apps/zcode-cli/packages/core/src/memory/extraction.ts)

- 记忆按工作区隔离。在一个工作区记录的事实在另一个工作区不可见。
- 注入的索引有上限。超过 `memoryMaxBytes` 时，超出部分不注入。
- 提取并非每轮都运行。没有合格用户文本的轮次、失败的轮次，以及直接写入了记忆的轮次，都会被跳过。
- 本地存储不等于本地推理。提取和注入的笔记都会到达所配置的模型。涉及机密的项目材料需要显式批准的模型路由。
- 在子目录中启动的会话过去会从工作目录推导记忆根，这可能在工作区下留下嵌套的 `.zcode/memory` 目录。本预设不再创建这些目录，也不发现、复制、移动、合并或删除任何已存在的目录。迁移或合并它们是需要运维者人工审查的手动操作。
