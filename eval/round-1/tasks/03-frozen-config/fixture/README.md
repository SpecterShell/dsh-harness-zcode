# Request limits

`app.limits.clamp(value, key)` returns `value` limited by the ceiling for `key`
in the limit file.

- The limit file defaults to `config/limits.json` and can be replaced with
  `LIMITS_PATH`, which the integration tests use.
- Every key in the file is a ceiling. Unknown keys fall back to `requests`.
- `config/limits.json` is generated by ops. Do not edit it by hand.

```python
from app.limits import clamp

clamp(150, "requests")  # 100
clamp(150, "burst")     # 250
```
